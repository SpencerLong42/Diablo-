# Diablo 4 build notes

## Season 15 – Warlock "Blazing Scream"
**[Season-15-Warlock-Blazing-Scream-Guide.md](Season-15-Warlock-Blazing-Scream-Guide.md)** is a step-by-step checklist that starts at level 70, after the Lord of Hatred campaign. It covers:

- Finishing the seasonal questline, keeping the **Splinter of Destruction**, and its full rank 1–24 reputation track
- The Season Rank ladder (I–IX), Season Blessings, and the Pit and Torment unlock order
- Setting up War Plans, Talismans, the Horadric Cube, mercenaries and the Codex
- The build in phases:
  - **Starter**: no uniques needed
  - **Midgame**: Elegy + Infernal Homunculus
  - **Endgame / Push / Speedfarm**: Mythic gear
  - The **Orbital Scream / Teleport** version

  Each phase lists skill points, the gear for every slot with aspects, affixes, tempers (manual names), masterwork targets and sockets, plus Soul Splinters, charms and mercenaries.
- Paragon boards, glyphs and their leveling order
- Where every unique drops, runeword and rune recipes, crafting order, survival notes and the repeating farm loop

Build reference: <https://mobalytics.gg/diablo-4/builds/warlock-blazing-scream>. The detailed data comes from Maxroll's and D4Guides' versions of the same build; see the guide's notes and sources.
